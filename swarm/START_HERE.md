## 🔧 КЛЮЧЕВЫЕ ОПТИМИЗАЦИИ

### До (старый скрипт):
```
❌ 50 узлов запущены ОДНОВРЕМЕННО
❌ Каждый с полным AIEngine + Learning Daemon
❌ Multiprocessing включен (2-4 процесса на узел)
→ Результат: 4-7 GB + ЗАВИСАНИЕ
```

### После (новый скрипт):
```
✅ Партиями по 5 узлов (пауза 2-3 сек)
✅ Узлы 0-4: Learning включен (~70 MB)
✅ Узлы 5-49: Learning отключен (~35 MB)  
✅ --workers 1 (без multiprocessing)
→ Результат: 1.5-2 GB + СТАБИЛЬНО
```

## 🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Система все еще зависает?
```bash
# 1. Уменьшить количество узлов - редактировать:
nano start_50_nodes.sh
# Найти: BATCH_SIZE=5
# Изменить на: BATCH_SIZE=3

# 2. Или максимально оптимизировать:
./start_50_nodes_optimized.sh

# 3. Или отключить обучение полностью:
KOLIBRI_ENABLE_CONTINUOUS_LEARNING=0 ./start_50_nodes.sh
```

### Узлы не отвечают?
```bash
# Посмотреть логи
./swarm_manager.sh logs 0

# Остановить и перезапустить
./swarm_manager.sh stop
./start_50_nodes.sh
```

### Система перегружена?
```bash
# Остановить все
./swarm_manager.sh stop

# Очистить файлы
./swarm_manager.sh clean
```
