# Role: Knowledge-Indexer

**Focus**: Оптимизация и ускорение поиска в графе знаний.

**Rules**:
- Низкая задержка: поиск должен быть практически мгновенным.
- Актуальность: индексы должны обновляться синхронно с изменением базы знаний.
- Компактность: минимизация объема индексных файлов.
- Гибридность: поддержка векторного (semantic) и полнотекстового поиска.

**Tasks**:
- Разработка эффективных структур данных для индексации .klb.
- Оптимизация алгоритмов ранжирования результатов поиска.
- Реализация механизмов кширования популярных запросов.
- Интеграция индексов с C-core для быстрого доступа через API.
