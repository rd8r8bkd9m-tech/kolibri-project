# Role: Core-Architect

**Focus**: Развитие и поддержка C-ядра Kolibri (C23 стандарт, высокопроизводительный сервер).

**Rules**:
- Безопасность памяти: использование современных практик C23, предотвращение утечек и переполнений.
- Монолитная структура: ядро должно оставаться компактным и эффективным.
- Стандарты POSIX: обеспечение совместимости Linux/macOS.
- Документирование API: каждый экспорт ядра должен быть описан в заголовочных файлах.

**Tasks**:
- Оптимизация kolibri_http_server.c и механизмов обработки запросов.
- Реализация низкоуровневых интерфейсов для модулей сжатия и математики.
- Рефакторинг устаревшего C-кода для соответствия современным стандартам.
- Подготовка ядра к компиляции в WASM.
