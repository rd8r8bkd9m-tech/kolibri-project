# Content Factory — Backlog (RU)

## Цель MVP
Автоматизированный контент‑конвейер с human‑in‑the‑loop: анализ → идеи → утверждение → производство → утверждение → публикация → аналитика → ROMI.

## Роли
- **Маркетолог** — запускает кампании, анализирует ROMI.
- **Редактор** — правит контент, утверждает.
- **Руководитель** — контроль рисков, бренд‑гайды.
- **Контент‑оператор** — публикация и планирование.

---

## Эпик 1. Аналитика и тренды
**Цель:** быстро получать список трендовых тем с объяснением.

### User Stories
1. **Как маркетолог**, я хочу запускать анализ по нише, чтобы получить 10–30 трендов с пояснениями.
   - Acceptance: список трендов, скоринг, объяснение «почему».
2. **Как редактор**, я хочу видеть источники/референсы, чтобы оценивать качество идей.
   - Acceptance: для каждой идеи ссылки/описания источников.

**Приоритет:** P0

---

## Эпик 2. Генерация идей
**Цель:** конвейер гипотез с привязкой к воронке.

### User Stories
1. **Как маркетолог**, я хочу получить 20+ идей с хуками и CTA.
2. **Как руководитель**, я хочу оценивать риск‑скоринг (бренд/юридика), чтобы блокировать опасные идеи.

**Приоритет:** P0

---

## Эпик 3. Согласования (Human‑in‑the‑Loop)
**Цель:** быстрые решения «ОК / правки / стоп».

### User Stories
1. **Как редактор**, я хочу утвердить идею одной кнопкой.
2. **Как редактор**, я хочу оставить правки и вернуть на этап.
3. **Как руководитель**, я хочу блокировать идеи с красными флагами.

**Приоритет:** P0

---

## Эпик 4. Производство контента
**Цель:** сценарии, структура, метаданные.

### User Stories
1. **Как редактор**, я хочу получать сценарий с хронометражем и структурой.
2. **Как контент‑оператор**, я хочу получать метаданные (описание, теги, заголовок).

**Приоритет:** P0

---

## Эпик 5. Публикация
**Цель:** автопостинг по расписанию.

### User Stories
1. **Как контент‑оператор**, я хочу планировать публикации по календарю.
2. **Как маркетолог**, я хочу генерировать UTM‑метки.

**Приоритет:** P1

---

## Эпик 6. Аналитика и ROMI
**Цель:** связать контент и метрики бизнеса.

### User Stories
1. **Как маркетолог**, я хочу видеть ROMI/ROAS по каждой единице контента.
2. **Как руководитель**, я хочу видеть вклад канала в выручку.

**Приоритет:** P0

---

## Эпик 7. Обучение конвейера
**Цель:** корректировать генерации на основе правок.

### User Stories
1. **Как редактор**, я хочу, чтобы мои правки влияли на будущие генерации.
2. **Как маркетолог**, я хочу авто‑рекомендации «что делать больше/меньше».

**Приоритет:** P1
