# Unconfirmed Reports Archive

Этот каталог содержит документы, которые временно выведены из основного контура планирования.

Причина: в них есть заявления о готовности фаз/результатов, которые требуют отдельной повторной верификации по коду, тестам и артефактам.

Текущий состав архива:

- `AGI_PHASE1_REPORT.md`
- `AGI_PROGRESS_REPORT.md`
- `PROJECT_COMPLETE.md`
- `FULL_PIPELINE_COMPLETE.md`
- `status_analysis.md`

Правило:

- Документ возвращается в рабочие `docs/` только после проверки "код + тест + воспроизводимый запуск".
