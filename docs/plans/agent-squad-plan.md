# План внедрения Kolibri Hive-Mind (Оркестратор + 20 Агентов + Home Server)

## 1. Концепция: Единый Организм Kolibri AI
Проект Kolibri — это единая операционная система и AGI-монорепозиторий (`UI <-> WASM <-> Python <-> C-Core`). Рой из 20+ агентов и Оркестратора создается не для дробления проекта, а для его одновременного, параллельного развития как единого целого. Агенты работают над одним общим контуром.
Для радикального ускорения разработки, тяжелые вычисления (C-core, тесты) выносятся на **Домашний Сервер**, пока UI/WASM собирается локально.

## 2. Архитектура Агентов Единого Проекта (21 Роль)

### 👑 Единый Оркестратор
1. **[Kolibri-Orchestrator]**: Управляет всем монорепозиторием. Видит весь путь данных от C-ядра до React-компонента. Не задает лишних вопросов, действует по ROADMAP.md.

### 🧠 C-Core & AI Engine (Движок Kolibri)
2. **[Core-Architect]**: Развитие C23-монолита (`kolibri_http_server.c`, память).
3. **[Compression-Scientist]**: Оптимизация фрактального/ANS сжатия.
4. **[Math-Engine]**: Улучшение решателя формул (`math_solver.c`).
5. **[C-Optimizer]**: SIMD-векторизация и производительность ядра.
6. **[AGI-Theorist]**: Архитектура World Model и Numeric Transformer.
7. **[Auto-Learner]**: Логика фонового обучения (`auto_learn.c`).

### 🌐 Knowledge & Data (Память Kolibri)
8. **[Data-Alchemist]**: Синтез `.klb` (баз знаний) и скриптов `.ks`.
9. **[Truth-Verifier]**: Самопроверка AGI, поиск галлюцинаций.
10. **[Knowledge-Indexer]**: Ускорение поиска по графу знаний.

### 🔌 Swarm Gateway (Связь с миром)
11. **[FastAPI-Gateway]**: Улучшение Python-шлюза (`ai_engine.py`, `ai_chat.py`).
12. **[Swarm-Networker]**: Логика нод, распределенные P2P-запросы.
13. **[GPU-Integrator]**: Интеграция CUDA/Metal-ускорителей.
14. **[Security-Auditor]**: Защита ключей, криптография, предотвращение утечек.

### 🖥️ Kolibri UI & WASM (Лицо Проекта)
15. **[UI-Integrator]**: Единый React/TypeScript фронтенд.
16. **[UX-Visionary]**: Mantine UI, опыт взаимодействия с чатом.
17. **[WASM-Bridger]**: Бесшовная компиляция C-ядра в браузер.
18. **[Streaming-Expert]**: Оптимизация SSE и рендеринга Markdown.

### 🏗️ Автоматизация & Разведка (Zero-Interaction Infra)
19. **[Cluster-DevOps]**: Авто-связка с Домашним Сервером (находит SSH ключи сам, настраивает `rsync` и `remote_exec`).
20. **[QA-Fuzzer]**: Жесткое тестирование монолита (все 70+ тестов CTest/Pytest).
21. **[Web-Scout]**: Автономный поиск свежих алгоритмов на arXiv/GitHub.

## 3. Интеграция MCP Серверов (Model Context Protocol)
Для полной автономизации рой будет использовать MCP-серверы, расширяющие базовые возможности:
1. **Remote-Execution MCP**: Позволяет агентам запускать тяжелые bash-команды (`make -j16`, `pytest`) напрямую на домашнем сервере без возни с экранами.
2. **Web-Search MCP**: Дает агентам [Web-Scout] и [AGI-Theorist] прямой доступ к arXiv и GitHub для поиска свежих papers по сжатию.
3. **SQLite MCP**: Прямой SQL-доступ для [Data-Alchemist] к локальным графам знаний.

## 4. Zero-Interaction Setup (План реализации без участия человека)
После единственного подтверждения этого плана, Оркестратор выполнит следующие шаги полностью автономно:

1. **Авто-обнаружение серверов**: Агент `Cluster-DevOps` молча просканирует `~/.ssh/config`, `~/.ssh/id_rsa` и `known_hosts` на вашем Mac. Он создаст скрипт `infra/remote_sync.sh`, который будет автоматически использовать найденные ключи (с флагом `BatchMode=yes`, чтобы не блокироваться на паролях).
2. **Тотальная генерация Skills**: В директории `/agents/hive/` будут созданы 21 максимально детализированных Markdown-инструкций. В каждой будет прописан жесткий запрет на вопросы пользователю — агенты должны решать проблемы сами или через Оркестратора.
3. **Установка MCP**: Конфигурация необходимых MCP серверов в среде проекта.
4. **Запуск Оркестратора**: Активация `Swarm-Coordinator`, который начнет читать `ROADMAP.md` и молча запускать суб-агентов (Front-end локально, C-core удаленно через SSH).
5. **Создание GEMINI.md**: Формирование "Конституции" роя, запрещающей прерывать пользователя без критической необходимости.
