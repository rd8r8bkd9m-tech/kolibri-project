# Calibri AI: Техническое задание (автопилот)

## Цель
Выкатить рабочий продукт Kolibri AI на `kolibriai.ru` с реальным AI-чатом, русским UI, мобильной и десктопной стабильностью, без моков в проде.

## Обязательные требования
1. Единый backend API для чата и моделей.
2. Реальный AI-ответ из backend (не заглушка).
3. Полностью русский интерфейс.
4. Светлая и тёмная тема.
5. Корректный мобильный UX: поле ввода видно и доступно.
6. Прод-деплой на Ubuntu с проверкой health.

## API-контракт (v1)
1. `POST /api/v1/ai/chat` — синхронный ответ.
2. `POST /api/v1/ai/chat/stream` — SSE streaming.
3. `GET /api/v1/ai/models` — статус основной модели.
4. `GET /api/v1/health/live` — liveness.
5. `GET /api/v1/health/ready` — readiness.

## Фазы
## Фаза 1: Стабилизация прода (текущая)
1. Исправить мобильный/десктопный layout чата.
2. Подключить фронтенд к реальным AI эндпоинтам.
3. Обеспечить fallback API для отказоустойчивости.
4. Деплой и smoke-check в проде.

## Фаза 2: Качество ответов
1. Нормализовать промпт-пайплайн backend.
2. Добавить оценку качества (latency, success rate, answer length).
3. Добавить базовые интеграционные тесты чата.

## Фаза 3: Память + RAG
1. Сохранение памяти пользователя в персистентном слое.
2. Индексация документов проекта и retrieval.
3. Ответы с источниками.

## Фаза 4: Продуктовый hardening
1. Наблюдаемость (логи, метрики, алерты).
2. Политика бэкапов.
3. Документация эксплуатации.

## Критерии готовности (DoD)
1. Прод отвечает на чат-запросы через backend API.
2. На мобильном поле ввода всегда доступно в режиме чата.
3. Нет англоязычных ключевых строк в UI.
4. Smoke-check проходит после каждого деплоя.
5. Есть отчёт по фазе 1 с фактами и метриками.
