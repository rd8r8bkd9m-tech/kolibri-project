# Kolibri AGI V2 Implementation Plan (Phase 4 Rollout)

## 🎯 Стратегическая цель AGI V2
Переход Kolibri от "Trustworthy Reasoner" (Система ответов) к "Autonomous Agent Ecosystem" (Система действий). Это развитие идей из `KOLIBRI_AGI_INNOVATION_ROLLOUT.md` (Phase 4) с опорой на успешный фундамент `KOLIBRI_30_DAY_WORLD_CLASS_PLAN.md`.

## 📌 Ключевые направления (The Next Scope)

### 1. Расширение Cognitive Core (Reasoning & Scale)
Вместо базовых definitional/causal ответов, ядро должно научиться строить глубокие аналитические цепочки:
- **Многоабзацные ответы ядра:** Развитие C-core composer для формирования связных текстов из нескольких смысловых блоков.
- **Deep Reasoning вопросы:** Поддержка сложных логических вопросов, требующих многошагового вывода (композиция 2+ формул).
- **Масштаб доменного покрытия:** Автоматизированное расширение обучающей базы за пределы базового набора знаний, переход к тысячам доменов.

### 2. Reasoning-Guided Action Loops (Система Действий)
Внедрение безопасных инструментов для агентов:
- **Безопасное использование тулов:** C-Core должен уметь генерировать вызовы API/инструментов с доказанной валидностью и аудитом (Digital Genome).
- **Autonomous Swarm Agents:** Узлы Swarm-сети получают возможность автономно решать задачи пользователя (сбор данных, проверка гипотез).
- **Интерфейс действий:** Расширение UI для визуализации не только мыслей агента, но и совершаемых им действий.

### 3. Persistent Learning & Swarm Consensus
Самообучающаяся P2P сеть в действии:
- **Непрерывное фоновое обучение:** Swarm-ноды должны автономно индексировать B2B базы (код, право, наука) без ручного вмешательства.
- **Усиленный консенсус:** Алгоритмы оценки надежности знаний при обучении на лету — автоматическая отбраковка галлюцинаций.
- **Демонстрация Swarm Scale:** Показательные бенчмарки, где кластер из 10-50 нод решает крупную задачу (например, парсинг юридической базы) в разы быстрее одной ноды.

### 4. B2B Интеграции & Enterprise
Подготовка к коммерческим внедрениям:
- **Интеграция с кодом (Dev-Assist):** Способность анализировать репозитории, находить баги, предлагать патчи.
- **Интеграция с правом и наукой:** Точный поиск и анализ по специализированным документам с гарантией отсутствия выдумок (strict no-fabrication).
- **On-premise Deployment:** Удобные kpack/Docker сборки для запуска всего кластера локально у Enterprise-клиента.

## 🚀 План реализации (Ближайшие шаги)

### Этап 1: Deep Reasoning & Long-form (Текущий фокус)
- [ ] Апгрейд генератора формул в C-core для композиции сложных ответов.
- [ ] Обучение ядра связывать несколько причинно-следственных связей в один ответ.
- [ ] Добавление Evals для многоабзацных генераций (качество + hit ratio).

### Этап 2: Tool Use Engine
- [ ] Проектирование формата `ToolCall` в протоколе C-Core.
- [ ] Интеграция первых 2-3 базовых инструментов (поиск, калькулятор, чтение файлов).
- [ ] Демо: "Колибри решает задачу, вызывая инструмент и возвращая проверенный результат".

### Этап 3: Autonomous Swarm B2B Pilot
- [ ] Настройка Continuous Ingestion pipeline.
- [ ] Тестовый прогон обучения кластера на массиве юридических/научных данных.
- [ ] Разработка B2B дашборда для контроля качества обучения и действий роя.
