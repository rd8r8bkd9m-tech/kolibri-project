## Как использовать новые возможности

### Запуск форматирования
```bash
# Сортировка импортов
isort . --profile black

# Форматирование кода
black .
```

### Запуск тестов с покрытием
```bash
pytest --cov=. --cov-report=html tests/
```

### Статический анализ C/C++
```bash
# Генерация compile_commands.json
cmake -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON

# Запуск clang-tidy
find . -name "*.c" -o -name "*.h" | xargs clang-tidy --config-file=.clang-tidy
```

### Линтинг Python
```bash
ruff check .
```
