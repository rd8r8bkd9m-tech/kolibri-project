# Программирование

Программирование — деятельность по созданию алгоритмов и программ для компьютеров и вычислительных систем. Программирование включает проектирование логики, описание данных, написание исходного кода, отладку, проверку поведения программы и улучшение её структуры, производительности и надёжности.
Пример из программирования: программа принимает входные данные, обрабатывает их по алгоритму и выдаёт результат пользователю или другой системе. Ещё один типичный случай программирования — автоматизация повторяющейся задачи, чтобы компьютер выполнял её быстрее, точнее и воспроизводимо.
