Алгоритм — это конечная последовательность чётко определённых инструкций для решения задачи.
Структура данных — способ организации и хранения данных для эффективного доступа.
Массив — это структура данных, хранящая элементы одного типа в непрерывной области памяти.
Связный список — это структура данных, где каждый элемент содержит указатель на следующий.
Стек — это структура данных с принципом LIFO: последний вошёл — первый вышел.
Очередь — это структура данных с принципом FIFO: первый вошёл — первый вышел.
Хеш-таблица — это структура данных, обеспечивающая доступ к элементам за O(1) в среднем.
Бинарное дерево поиска — это дерево, где левый потомок меньше родителя, а правый больше.
Граф — это структура данных, состоящая из вершин и рёбер между ними.
Сортировка пузырьком — простой алгоритм с временной сложностью O(n²).
Быстрая сортировка (quicksort) — эффективный алгоритм со средней сложностью O(n log n).
Сортировка слиянием — стабильный алгоритм с гарантированной сложностью O(n log n).
Поиск в глубину (DFS) обходит граф, углубляясь до самых дальних вершин.
Поиск в ширину (BFS) обходит граф по уровням, находя кратчайший путь.
Алгоритм Дейкстры находит кратчайший путь от одной вершины до всех остальных.
Жадный алгоритм на каждом шаге делает локально оптимальный выбор.
Динамическое программирование решает задачу, разбивая её на перекрывающиеся подзадачи.
Рекурсия — это метод, при котором функция вызывает сама себя.
Временная сложность O(n) означает линейную зависимость времени от размера входных данных.
Пространственная сложность определяет объём памяти, необходимый алгоритму.
Операционная система — программное обеспечение, управляющее аппаратными ресурсами компьютера.
Процесс — это экземпляр выполняющейся программы с собственным адресным пространством.
Поток — это лёгковесная единица исполнения внутри процесса.
Виртуальная память позволяет программам использовать больше памяти, чем физически доступно.
Файловая система организует данные на диске в виде файлов и каталогов.
TCP/IP — основной протокол интернета, обеспечивающий надёжную передачу данных.
HTTP — протокол прикладного уровня для передачи гипертекстовых документов.
DNS преобразует доменные имена в IP-адреса.
Шифрование — процесс преобразования данных в нечитаемый формат для защиты.
Хеш-функция преобразует данные произвольной длины в строку фиксированной длины.
Компилятор переводит исходный код программы в машинный код.
Интерпретатор исполняет программу построчно без предварительной компиляции.
База данных — это организованная коллекция структурированных данных.
SQL — язык структурированных запросов для работы с реляционными базами данных.
NoSQL — базы данных, не использующие реляционную модель (документные, графовые, key-value).
API — программный интерфейс, позволяющий приложениям взаимодействовать друг с другом.
REST — архитектурный стиль для построения веб-сервисов.
Микросервисы — архитектурный подход, где приложение состоит из небольших независимых сервисов.
Контейнеризация (Docker) — упаковка приложения со всеми зависимостями в изолированный контейнер.
Kubernetes — система оркестрации контейнеров для автоматизации развёртывания.
