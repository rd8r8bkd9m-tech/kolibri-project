Python — высокоуровневый интерпретируемый язык программирования общего назначения. Создан Гвидо ван Россумом в 1991 году. Python известен своим простым и читаемым синтаксисом.

Ключевые особенности Python:
- Динамическая типизация
- Автоматическое управление памятью (сборщик мусора)
- Поддержка ООП, функционального и процедурного программирования
- Обширная стандартная библиотека
- Огромная экосистема пакетов (PyPI)

Популярные Python-фреймворки:
- Django — полнофункциональный веб-фреймворк
- Flask — лёгкий веб-фреймворк
- FastAPI — современный асинхронный API-фреймворк
- NumPy — библиотека для научных вычислений
- Pandas — анализ данных
- PyTorch, TensorFlow — глубокое обучение

Язык C:
C — низкоуровневый компилируемый язык программирования. Создан Деннисом Ритчи в 1972 году. C даёт прямой контроль над памятью через указатели и является основой операционных систем (Linux, Windows kernel).

C23 — последний стандарт языка C (2023). Нововведения: auto для вывода типов, constexpr, nullptr, улучшенные атрибуты, typeof. Kolibri OS использует C23 как основной язык для высокопроизводительного ядра.

WebAssembly (WASM):
WebAssembly — это бинарный формат инструкций для виртуальной машины, работающей в браузере. WASM позволяет запускать код C/C++/Rust в вебе с производительностью, близкой к нативной. Kolibri компилирует своё C-ядро в WASM для работы в браузере.

React:
React — JavaScript-библиотека для создания пользовательских интерфейсов. Создана Facebook в 2013 году. Использует виртуальный DOM, компонентный подход и JSX-синтаксис. Hooks (useState, useEffect) позволяют управлять состоянием в функциональных компонентах.

TypeScript:
TypeScript — надмножество JavaScript с статической типизацией. Разработан Microsoft. Компилируется в JavaScript. Обеспечивает раннее обнаружение ошибок и лучшую поддержку IDE.

REST API:
REST (Representational State Transfer) — архитектурный стиль для построения веб-сервисов. Основные принципы: использование HTTP-методов (GET, POST, PUT, DELETE), адресация ресурсов через URL, stateless взаимодействие, обмен данными в JSON/XML.

Docker:
Docker — платформа контейнеризации. Контейнер — это изолированная среда для запуска приложения со всеми зависимостями. Dockerfile описывает сборку образа. Docker Compose управляет многоконтейнерными приложениями.

Git:
Git — распределённая система контроля версий. Основные операции: commit (фиксация изменений), branch (ветвление), merge (слияние), push/pull (синхронизация с удалённым репозиторием). GitHub — популярная платформа для хостинга Git-репозиториев.
