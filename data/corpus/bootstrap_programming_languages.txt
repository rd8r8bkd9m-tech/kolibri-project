Python — высокоуровневый язык программирования с динамической типизацией.
Python используется для машинного обучения, веб-разработки и научных вычислений.
JavaScript — основной язык программирования для веб-браузеров.
TypeScript — надмножество JavaScript с поддержкой статической типизации.
Java — объектно-ориентированный язык с принципом 'write once, run anywhere'.
C — системный язык программирования, близкий к аппаратному уровню.
C++ — расширение языка C с поддержкой объектно-ориентированного программирования.
Rust — системный язык с гарантиями безопасности памяти без сборщика мусора.
Go — язык от Google, оптимизированный для многопоточности и сетевых сервисов.
Kotlin — современный язык для JVM, используемый для разработки Android-приложений.
Swift — язык программирования от Apple для iOS и macOS.
PHP — серверный язык, широко используемый для веб-разработки.
Ruby — динамический язык, известный фреймворком Ruby on Rails.
Scala — язык, объединяющий объектно-ориентированное и функциональное программирование.
Haskell — чисто функциональный язык программирования с ленивыми вычислениями.
SQL — декларативный язык для управления данными в реляционных СУБД.
R — язык статистических вычислений и визуализации данных.
MATLAB — среда для численных вычислений и инженерных расчётов.
Perl — язык для обработки текста и системного администрирования.
Lua — лёгкий встраиваемый скриптовый язык.
