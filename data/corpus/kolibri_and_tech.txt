Kolibri OS — это экспериментальная операционная система и платформа для искусственного интеллекта, построенная на принципах Числового Формульного Мышления.

Числовое Мышление (Number Thinking) — уникальный подход к ИИ, где все знания хранятся в виде числовых паттернов. Каждое слово преобразуется в 64-цифровой числовой отпечаток через хеш-функцию DJB2. Это позволяет представлять и обрабатывать текстовую информацию через математические операции с числами.

Граф знаний Kolibri — это структура данных, хранящая связи между словами. Каждое слово — это вершина с числовым паттерном. Рёбра между словами имеют веса, основанные на совместной встречаемости слов в обучающих текстах. Чем чаще два слова встречаются рядом, тем сильнее связь между ними.

Формулы в Kolibri — это эволюционные программы, записанные как последовательности из 4000 цифр (геном). Каждая формула — это вычислительная сеть до 500 слоёв с ResNet-подобной архитектурой (есть fast-режим 100 слоёв). Формулы эволюционируют через генетический алгоритм: мутация, кроссовер, селекция лучших.

Fitness формулы — это мера её качества. Fitness оценивается по способности формулы трансформировать числовой паттерн одного слова в паттерн семантически связанного слова из графа знаний. Лучшие формулы сохраняются, худшие заменяются потомками лучших.

Архитектура Kolibri включает три основных компонента:
1. Ядро на языке C (backend/src/) — быстрые вычисления: хеширование, паттерны, формулы
2. Python-сервис (backend/service/) — FastAPI сервер с AI-движком, обучением, API
3. Фронтенд на React (frontend/) — веб-интерфейс с чатом и визуализацией через WebAssembly

Kolibri использует WebAssembly (WASM) для запуска C-ядра прямо в браузере. Это позволяет выполнять числовые вычисления на стороне клиента без обращения к серверу.

Sentence Store — числовое хранилище предложений в Kolibri. Каждое предложение кодируется в последовательность цифр (3 цифры на каждый байт UTF-8). При поиске ответа система находит наиболее релевантные предложения через индекс слов и формульный re-ranking.

Обучение Kolibri происходит через загрузку текстовых документов. Система токенизирует текст, добавляет слова в граф знаний, создаёт рёбра между соседними словами и сохраняет предложения в Sentence Store. Формулы обучаются предсказывать семантические связи между словами.

Kolibri Archiver — модуль сжатия данных, использующий принципы числового мышления для компрессии файлов. Поддерживает форматы .kolibri и .klb.

KolibriScript (.ks) — предметно-ориентированный язык для создания инструкций AI-ноды. Позволяет определять знания, вопросы-ответы, скрипты поведения и правила обработки запросов.

Нода Kolibri (kolibri_node) — автономный AI-агент, который может отвечать на вопросы, обучаться на текстах и обмениваться знаниями с другими нодами в сети (swarm). Каждая нода содержит свой граф знаний и набор эволюционных формул.

Программирование — процесс создания компьютерных программ с использованием языков программирования. Основные парадигмы: процедурное, объектно-ориентированное, функциональное, логическое программирование.

Python — высокоуровневый язык программирования общего назначения. Создан Гвидо ван Россумом в 1991 году. Широко используется в науке о данных, машинном обучении, веб-разработке. Отличается простым синтаксисом и обширной экосистемой библиотек: NumPy, Pandas, TensorFlow, PyTorch.

JavaScript — язык программирования для веб-разработки, работает в браузерах и на серверах (Node.js). TypeScript — надмножество JavaScript с типизацией.

C — низкоуровневый язык программирования системного уровня, созданный Деннисом Ритчи в 1972 году. Используется для написания операционных систем, драйверов, встроенных систем. Kolibri OS использует C23 (последний стандарт C) для ядра.

Алгоритмы сжатия данных: LZ77 (основа DEFLATE, gzip, zip), LZ78, LZW (GIF), Хаффмана (сжатие по частотам символов), арифметическое кодирование, BWT (преобразование Барроуза-Уилера), PPM (предсказание по частичному совпадению).

Компрессия без потерь (lossless) — сжатие, при котором данные восстанавливаются точно. Примеры: ZIP, GZIP, LZMA, Brotli, Zstandard. Компрессия с потерями (lossy) — сжатие с потерей части информации. Примеры: JPEG, MP3, H.264.

Наука о данных (Data Science) — междисциплинарная область, объединяющая статистику, математику и программирование для извлечения знаний из данных. Включает сбор, очистку, анализ, визуализацию и моделирование данных.
