Искусственный интеллект — область информатики, создающая системы, имитирующие разумное поведение.
Машинное обучение — подмножество ИИ, где модели учатся на данных без явного программирования.
Глубокое обучение — подмножество машинного обучения, использующее многослойные нейронные сети.
Нейронная сеть — вычислительная модель, вдохновлённая структурой биологического мозга.
Перцептрон — простейшая нейронная сеть с одним слоем нейронов.
Свёрточная нейронная сеть (CNN) специализируется на обработке изображений.
Рекуррентная нейронная сеть (RNN) обрабатывает последовательные данные.
Трансформер — архитектура нейронных сетей, основанная на механизме внимания.
GPT — генеративный предобученный трансформер для генерации текста.
BERT — модель двунаправленного кодировщика для понимания языка.
Обучение с учителем — модель учится на размеченных данных (вход → правильный выход).
Обучение без учителя — модель находит скрытые структуры в неразмеченных данных.
Обучение с подкреплением — агент учится через взаимодействие со средой и получение наград.
Функция потерь измеряет расхождение между предсказанием модели и правильным ответом.
Градиентный спуск — метод оптимизации, минимизирующий функцию потерь.
Обратное распространение ошибки — алгоритм вычисления градиентов в нейронных сетях.
Переобучение — когда модель слишком хорошо запоминает обучающие данные и плохо обобщает.
Регуляризация — методы предотвращения переобучения (L1, L2, dropout).
Батч-нормализация ускоряет обучение нейронных сетей, нормализуя входы слоёв.
Transfer learning — использование предобученной модели для новой задачи.
Embedding — плотное векторное представление дискретных объектов (слов, пользователей).
Word2Vec — алгоритм получения векторных представлений слов (CBOW и Skip-gram).
Attention механизм позволяет модели фокусироваться на релевантных частях входа.
Self-attention — внимание элементов последовательности друг к другу.
Токенизация — разбиение текста на минимальные единицы (токены) для обработки моделью.
Температура — параметр, контролирующий случайность генерации текста.
Few-shot learning — обучение модели на нескольких примерах.
Zero-shot learning — модель решает задачу без обучающих примеров.
Кластеризация — группировка объектов по сходству (K-Means, DBSCAN, иерархическая).
Метод главных компонент (PCA) — снижение размерности данных.
