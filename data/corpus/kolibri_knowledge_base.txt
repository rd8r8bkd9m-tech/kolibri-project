Kolibri OS — это гибридная платформа для искусственного интеллекта, написанная на C23, Python и WebAssembly.

Основной концепт Kolibri — «Числовое мышление» (Number-Thinking). Вместо классических нейронных сетей с обратным распространением ошибки, Kolibri использует эволюционную компрессию знаний в компактные числовые геномы. Каждый геном — это 64-значная строка, представляющая семантическое состояние AI-агента.

Архитектура Kolibri:
1. Ядро (C23) — реализует ReasonBlock-логику геномов, математические ядра для инференса и генерации текста, управление памятью.
2. API инференса — поддерживает 5 стратегий: DIRECT (прямой запрос), FORMULA (через формулы сжатия), LOGICAL (логический вывод), CHAIN (цепочка рассуждений), HYBRID (комбинированный).
3. Генерация текста — стратегии: GREEDY (жадный), BEAM (лучевой поиск), SAMPLING (выборка), FORMULA (через формулы).
4. База знаний — индексирование и поиск документов через KolibriKnowledgeIndex.

Модель KLM (Kolibri Language Model) хранит знания в формате хеш-таблиц фиксированного размера:
- До 128K паттернов
- До 256K связей (edges)
- Максимальный размер файла 50 МБ
- Бинарный формат .klm

Обучение модели:
- Веб-краулер на C скачивает страницы из интернета
- Corpus Trainer извлекает текст и токенизирует его
- Mass Trainer обучает .klm модель на корпусе текстов
- Поддерживается инкрементальное обучение — можно добавлять знания без перезаписи

Архивер Kolibri:
- Собственный алгоритм сжатия на основе формульной компрессии
- Поддержка многоуровневого сжатия
- Формат .kolibri для архивов

Python-бэкенд:
- FastAPI сервис для REST API
- Автономный AI-агент (поиск → краулинг → обучение)
- Веб-краулер с поддержкой DuckDuckGo, Wikipedia, Bing
- Векторное хранилище на SQLite с косинусным сходством

Фронтенд:
- React 18 + TypeScript + Vite
- Темная/светлая тема
- Вкладки: Чат, Краулер, AI Агент, Знания, Задачи, Терминал, Настройки
