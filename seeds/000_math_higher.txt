Высшая математика: базовые определения и формулы для Kolibri AI.

Предел функции по Коши:
lim_{x->a} f(x)=L, если для любого epsilon > 0 существует delta > 0,
такое что из 0 < |x-a| < delta следует |f(x)-L| < epsilon.

Непрерывность:
Функция f непрерывна в точке a, если lim_{x->a} f(x)=f(a).

Производная:
f'(x)=lim_{h->0}(f(x+h)-f(x))/h.
Геометрический смысл: угловой коэффициент касательной.

Правила дифференцирования:
(u+v)'=u'+v'
(uv)'=u'v+uv'
(u/v)'=(u'v-uv')/v^2
(f(g(x)))'=f'(g(x))*g'(x)

Таблица производных:
(x^n)'=n*x^(n-1)
(e^x)'=e^x
(ln x)'=1/x
(sin x)'=cos x
(cos x)'=-sin x

Важный пример:
d/dx sin(x^2)=2x*cos(x^2).

Первообразная и интеграл:
F'(x)=f(x) означает, что F — первообразная функции f.
Неопределенный интеграл: ∫f(x)dx=F(x)+C.

Интегрирование по частям:
∫u dv = u*v - ∫v du.

Определенный интеграл:
∫_a^b f(x)dx = F(b)-F(a) (формула Ньютона-Лейбница).

Ряды:
Необходимое условие сходимости ряда Σa_n: a_n -> 0.
Признак Даламбера:
если lim |a_{n+1}/a_n| = q < 1, ряд сходится;
если q > 1, ряд расходится.

Линейная алгебра:
Матрица A обратима тогда и только тогда, когда det(A) != 0.
Эквивалентно: rank(A)=n и столбцы A линейно независимы.

Собственные значения и векторы:
Собственные значения λ определяются из det(A-λI)=0.
Собственный вектор v != 0 удовлетворяет Av=λv.

Кратности:
Алгебраическая кратность — кратность корня λ в характеристическом многочлене.
Геометрическая кратность — dim Ker(A-λI).

Линейный оператор:
T(ax+by)=aT(x)+bT(y).
Формула размерностей:
dim Ker(T) + dim Im(T) = dim V.

Дифференциальные уравнения:
Линейное ДУ первого порядка:
y' + p(x)y = q(x).
Интегрирующий множитель:
mu(x)=exp(∫p(x)dx).
После умножения: (mu*y)' = mu*q(x).
Решение:
y=(1/mu)*(∫mu*q(x)dx + C).

Теория вероятностей:
Формула полной вероятности:
P(B)=Σ P(B|A_i)P(A_i), где {A_i} — полная группа событий.

Формула Байеса:
P(A_i|B)=P(B|A_i)P(A_i)/P(B).

Математическое ожидание и дисперсия:
E[X] — среднее значение случайной величины.
Var(X)=E[(X-E[X])^2].

Комплексный анализ:
z=x+iy, |z|=sqrt(x^2+y^2).
Формула Эйлера:
e^(i*phi)=cos(phi)+i*sin(phi).

Условия Коши-Римана для f(z)=u(x,y)+i*v(x,y):
u_x=v_y
u_y=-v_x

Численные методы:
Метод Ньютона:
x_{n+1}=x_n - f(x_n)/f'(x_n).

Короткие Q/A:
Вопрос: Когда матрица обратима?
Ответ: Когда ее определитель не равен нулю.

Вопрос: Что такое предел по Коши?
Ответ: Это epsilon-delta определение предела функции.

Вопрос: Что выражает формула Байеса?
Ответ: Апостериорную вероятность через априорную и правдоподобие.

Вопрос: Как найти производную sin(x^2)?
Ответ: 2x*cos(x^2).

Вопрос: Что такое условия Коши-Римана?
Ответ: Равенства u_x=v_y и u_y=-v_x для вещественной и мнимой частей аналитической функции.
