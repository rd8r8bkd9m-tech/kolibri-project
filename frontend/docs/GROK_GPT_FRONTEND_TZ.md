# Kolibri Frontend Redesign TЗ (Grok/GPT-like)

## 1. Цель
Собрать профессиональный чатовый интерфейс уровня production, визуально и по UX близкий к `grok.com` и современным GPT-интерфейсам:
- темная графитовая эстетика,
- clean/utility layout,
- быстрый и понятный сценарий «история чатов -> диалог -> отправка -> ответ»,
- полностью рабочая мобильная версия.

## 2. Ограничения и совместимость
- Технологии: React + TypeScript + Vite (без смены стека).
- Не ломать существующие backend-эндпоинты (`/api/v1/ai/chat`, `/api/v1/crawl`, `/api/v1/ai/reload`).
- Сохранить текущую логику локальной истории и сессий чатов.
- Не внедрять тяжелые UI-фреймворки.

## 3. UX-референс (что берем из Grok/GPT-паттернов)
- Левый сайдбар: бренд, кнопка нового чата, поиск, история.
- Основной холст: верхняя панель, лента сообщений, фиксированный composer.
- Визуальная иерархия: пользовательские сообщения компактнее, ассистентские — читабельные, с контрастным ритмом.
- Встроенные quick prompts на пустом чате.
- Мобильный off-canvas сайдбар + sticky composer + safe-area отступы.

## 4. Что реализуем
### 4.1 Layout
- Новый адаптивный shell:
  - Desktop >= 980px: постоянный сайдбар + контент.
  - Tablet 700-979px: компактный сайдбар, контент в приоритете.
  - Mobile < 700px: off-canvas меню, затемнение фона, кнопка меню.
- Вся структура на CSS grid/flex с `min-width: 0`, чтобы не было overflow-багов.

### 4.2 Chat screen
- Хедер диалога: название, подпись режима, действия.
- Лента сообщений с четкими состояниями:
  - initial empty state,
  - loading answer,
  - error bubble.
- Composer:
  - textarea auto-grow,
  - Enter — отправка, Shift+Enter — новая строка,
  - send/stop visual states,
  - сохранение доступности и фокус-логики.

### 4.3 Visual system
- Тема: graphite + cyan accent, без purple bias.
- Типографика:
  - UI: `Space Grotesk` (fallback: `Manrope`, `Segoe UI`, sans-serif),
  - mono: `IBM Plex Mono`, `JetBrains Mono`, monospace.
- Глобальные токены:
  - background, border, text, accent, shadow, radius, spacing.
- Фон: несколько radial-gradient слоев + легкая текстура/blur.
- Анимации: fade/slide-in для layout и сообщений, мягкий hover/focus.

### 4.4 Mobile-first критерии
- Тап-зоны >= 40px.
- Скрытие вторичных действий на узких экранах.
- Sticky composer с учетом `safe-area-inset-bottom`.
- Корректный скролл сообщений без перекрытия composer.
- Управление клавиатурой: input не уходит за экран.

## 5. Accessibility
- Контраст текста не ниже WCAG AA для основных элементов.
- Видимый focus ring у интерактивных элементов.
- `aria-label` для icon-only кнопок.
- `prefers-reduced-motion` для отключения интенсивных анимаций.

## 6. Производительность
- Без новых тяжелых зависимостей.
- Минимум лишних re-render, useMemo/useCallback для горячих участков.
- Избегать сложных box-shadow и фильтров на массовых элементах списка.

## 7. План работ
1. Создать централизованный stylesheet для shell + chat.
2. Переписать `ManusLayout` под новую архитектуру классов.
3. Переписать `ChatTab` на новый UI-композер и message-feed.
4. Обновить глобальные стили и токены.
5. Собрать проект и проверить responsiveness.

## 8. Definition of Done
- [ ] Визуально новая структура чата в стиле Grok/GPT.
- [ ] Рабочая история чатов, поиск, новый чат.
- [ ] Рабочая отправка/получение сообщений через backend API.
- [ ] Полностью рабочая мобильная версия (меню, чат, composer).
- [ ] Проект собирается командой `npm run build`.
