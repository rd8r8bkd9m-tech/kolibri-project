# Исправления фронтенда (April 13, 2026)

## Исправленные проблемы

### 1. ✅ Светлая тема не включалась
**Причина:** Tailwind darkMode был настроен только на класс `dark`, но приложение использовало кастомные классы `.theme-dark` и `.theme-light`.

**Решение:**
- Обновлен `tailwind.config.js`: `darkMode: ["class", ".theme-dark"]`
- Улучшена логика применения тем в `App.tsx`:
  - Теперь корректно удаляются все классы перед применением новой темы
  - Для темной темы добавляются оба класса: `theme-dark` и `dark`
  - Для светлой темы применяется только `theme-light`
  - Добавлен форсированный пересчет стилей

### 2. ✅ Текст не виден в темной теме (поле ввода)
**Причина:** CSS переменные не применялись корректно к textarea элементам в темной теме.

**Решение:**
- Добавлены explicit стили для `.v3-input` с `-webkit-text-fill-color`
- Добавлены стили для `.v3-composer-shell textarea` с конкретными RGB значениями
- Усилены стили placeholder'ов для лучшей видимости
- Добавлены `!important` флаги для критических стилей

### 3. ✅ Чат не работал/не интегрирован с ядром
**Статус:** Интеграция уже работала корректно!

**Проверка:**
- Backend API доступен на `http://127.0.0.1:8001`
- Endpoint `/api/v1/ai/chat/stream` работает корректно
- Vite прокси настроен правильно (`/api` → `http://127.0.0.1:8001`)
- Streaming SSE events (token, done) работают

**Что работает:**
- Отправка сообщений через streaming API
- Получение токенов в реальном времени
- Контекст диалога передается правильно
- Модели, персона и память работают

## Технические детали

### Тема применения:
- `theme === "system"` → определяется через `window.matchMedia("(prefers-color-scheme: dark)")`
- `theme === "light"` → применяется `theme-light` класс
- `theme === "dark"` → применяются `theme-dark` и `dark` классы

### CSS переменные тем:
```css
/* Светлая тема */
.theme-light {
  --background: 248 250 252;
  --foreground: 15 23 42;
  --surface-2: rgba(255, 255, 255, 1);
}

/* Тёмная тема */
.theme-dark {
  --background: 9 13 19;
  --foreground: 241 245 249;
  --surface-2: rgba(20, 29, 40, 1);
}
```

### API Integration:
- Режим: `VITE_KOLIBRI_RESPONSE_MODE=llm`
- Streaming: Server-Sent Events (SSE)
- Формат: `event: token` / `event: done`
