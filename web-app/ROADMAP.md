# Kolibri AI - Roadmap to AGI

## Текущая версия: v0.1 (Прототип)

### ✅ Реализовано в v0.1:
- **Базовое сжатие/декомпрессия** (алгоритм Kolibri)
- **Веб-интерфейс** (адаптивный, с вкладками)
- **История операций** (с экспортом в JSON)
- **Статистика использования**
- **AGI Core v0.1** (прототип когнитивного ядра):
  - Perception Layer (анализ энтропии, паттернов)
  - Cognitive Layer (выбор стратегии)
  - Learning Layer (адаптация эвристик)
  - Базовая классификация данных

## 🧠 Архитектура AGI ядра

```
┌─────────────────────────────────────────────────────────┐
│                    Perception Layer                      │
│  • Анализ энтропии  • Распознавание паттернов           │
│  • Классификация    • Извлечение признаков              │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                    Cognitive Layer                       │
│  • Граф знаний      • Выбор стратегии                   │
│  • Планирование     • Оценка уверенности                │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                     Action Layer                         │
│  • Сжатие           • Декомпрессия                      │
│  • Оптимизация      • Валидация                         │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                    Learning Layer                        │
│  • Обратная связь   • Обновление весов                  │
│  • Адаптация        • Долговременная память             │
└─────────────────────────────────────────────────────────┘
```

## 🚀 Быстрый старт

```bash
# Локальный запуск
cd web-app
python -m http.server 8080

# Открыть в браузере
http://localhost:8080
```

## 🌐 Деплой на kolibriai.ru

1. Скопируйте файлы из `/web-app/` в директорию сервера
2. Настройте HTTPS
3. Включите WebSocket для реального времени
4. Запустите фоновый процесс для обучения модели
